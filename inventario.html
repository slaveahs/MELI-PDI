O que é o Inventário (ICQA)?

GUARDIÃO DA VERDADE

O ICQA (Inventory Control & Quality Assurance) atua como a auditoria contínua do Centro de Distribuição. Sua missão é garantir que a quantidade física nas prateleiras seja um espelho exato do que consta no sistema WMS.

No modelo Fulfillment, o inventário não para a operação. Ele é cíclico, dinâmico e contínuo, ocorrendo em paralelo ao fluxo de Inbound e Outbound.

🚫

Evitar Falso Positivo

O sistema diz que há 10 iPhones, mas não há nenhum. Sem ICQA, o cliente compra e o pedido é cancelado (Shortage crítico).

👻

Falso Negativo

Há produtos no Bin, mas o sistema acusa 0. O item vira um "fantasma", ocupando espaço físico e perdendo vendas de um estoque real.

💰

Saúde Financeira

Cada unidade divergente representa capital bloqueado ou perda contábil. O estoque é dinheiro materializado nas prateleiras.

🕵️

Gaps de Processo

Mais do que contar, o ICQA identifica onde o erro nasceu. Falha no Stow? Erro de bipagem no Picking? Avarias ocultas?

Tipos de Contagem Contínua

Passe o mouse sobre os cards para decodificar os protocolos de auditoria (Audit Count Modes).

SBC

Simple Bin Count

HOVER TO DECODE

Simple Bin Count

Contagem cega focada apenas na quantidade total de itens físicos no Bin, independentemente do EAN (código de barras).

Gatilho: Verificação rápida de densidade e lotação. O sistema apenas pergunta: "Quantos itens você vê aí?"
CC

Cycle Count

HOVER TO DECODE

Cycle Count

Contagem profunda e detalhada. O auditor deve esvaziar o Bin e bipar EAN por EAN. Valida a identidade de cada produto.

Gatilho: Divergência detectada no SBC ou cronograma contínuo de auditoria de qualidade (Acuracidade).
SRC

Search Count

HOVER TO DECODE

Search Count

Contagem investigativa. O operador busca por um item específico (ASIN/EAN) que o sistema acredita estar perdido em uma zona ou bin.

Gatilho: Um Picker relatou "Item Não Encontrado" (Shortage) em um pedido de cliente ativo.

Problem Solver: Investigador de Dados

ROOT CAUSE ANALYSIS (RCA)

O Problem Solver do ICQA não é apenas um "corretor de erros". Ele é um analista de dados cuja missão é descobrir a Causa Raiz da divergência. Tratar o sintoma sem curar a doença faz o erro voltar.

[+] Add Sistêmico (Overage)

Produto existe fisicamente, mas o WMS desconhece. O PS insere o item no inventário (ganho contábil) após verificar se não pertence a outro bin ou se não sofreu "Missing" em outra estação.

[-] Delete Sistêmico (Shortage)

Produto consta no WMS, mas o físico não existe. O PS deve declarar a perda do item (despesa contábil) apenas após esgotar todas as buscas físicas no entorno do bin.

Regras de Ouro (Golden Rules ICQA)

✓

Acuracidade acima de Velocidade

No ICQA, o tempo não é a métrica principal. Um erro na contagem de auditoria destrói a confiança do sistema. Conte duas vezes se necessário.

✓

Esvazie o Bin

Nunca conte itens dentro da prateleira. Retire tudo, coloque no tote de apoio, conte na superfície plana e devolva organizando.

✓

Inspecione os seis lados

Valide se o produto não sofreu avaria (leaks, amassados, violação). Um item no endereço certo mas quebrado é uma divergência de qualidade.

✓

Dúvida = Escalação

EAN ilegível? Produto sem etiqueta? Se não há certeza absoluta da identidade do item, ele deve ser isolado para o Problem Solver.

O CASO DO PRODUTO FANTASMA

Cenário: Um Picker reportou um "Shortage" (não encontrou o produto) no Bin 04-A-12. O sistema diz que há 1 unidade de um Relógio Luxo. Você chega ao Bin e ele parece vazio à primeira vista.

Amnesty Flow (Itens Órfãos)

O Amnesty é o processo de coletar itens encontrados "caídos" ou "esquecidos" fora de seus Bins.

  • • Itens coletados são levados para a Amnesty Box.
  • • O Problem Solver ICQA bipa o item e o bin de origem.
  • • O item é reintegrado ao sistema (Add sistêmico).
  • • Sem punição: O foco é a integridade do estoque.

Dicionário ICQA

Overage (Sobra) +
Quando há mais itens físicos no Bin do que o registrado no WMS. Requer um "Add" sistêmico.
Shortage (Falta) +
Quando o sistema acusa um produto que não está fisicamente no endereço. Requer um "Delete" após busca exaustiva.
Scrap (Dano) +
Itens que perdem sua condição de venda por avaria física ou validade expirada. São removidos do estoque "bom".
Bin Sujo +
Endereço com itens de SKUs diferentes misturados sem organização, dificultando a contagem e o picking.
