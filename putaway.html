Conceito & Utilidade

🏗️

O que é o Putaway?

O Putaway (Stow) é a fase crítica onde o produto encerra sua transição do recebimento e ganha um endereço fixo. É o processo de alocar o item em uma célula física (Bin) e vinculá-lo via WMS, transformando "carga" em "estoque disponível".

🎯

Precisão Sistêmica

A acuracidade de inventário nasce aqui. Se um produto é guardado sem bipagem ou em local errado, ele se torna um "item fantasma": existe fisicamente, mas é invisível para o sistema de vendas, gerando perdas financeiras.

01. Disponibilidade

Só existe venda se o Picker souber exatamente onde o produto está.

02. Densidade

Otimização do espaço: itens pequenos em bins pequenos, aproveitando 100% do CD.

03. Rotação

Produtos de alta rotatividade em locais de fácil acesso (Power Zone).

Inventory Divergence Control

Quando o mundo físico e o sistêmico discordam, o Problem Solver entra em cena para restaurar a verdade do estoque.

📏

Erro de Cubagem (Master Data)

O sistema envia um item grande para um bin pequeno. O PS deve medir o produto, atualizar o cadastro mestre e liberar a nova alocação.

📊

Bin Cheio (Físico vs Virtual)

O WMS indica "Bin Vazio", mas há produtos lá. O PS realiza a auditoria (Cycle Count) para limpar o endereço.

📉

Falta no Tote (Shortage)

O sistema espera 10 itens, mas só existem 9. Investigação imediata para evitar furos de estoque na entrada.

📈

Sobra no Tote (Overage)

Item sem registro no tote atual. O PS deve identificar a origem e reintegrar o item ao fluxo correto.

Regras de Ouro do Stower

✔️ Bipou, Guardou

Sincronismo Total

Nunca bipa o produto e o guarda minutos depois. O registro deve ser em tempo real.

✔️ Visibilidade

Faceamento

O código de barras (EAN) deve estar sempre voltado para a frente do bin.

❌ Mistura Semelhante

Evite Confusão

Nunca coloque SKUs visualmente parecidos no mesmo bin. Risco de erro no Picking.

❌ Tetris Forçado

Integridade

Se o item não entra folgado, o bin está cheio. Forçar causa avarias no produto.

✔️ Power Zone

Ergonomia

Itens pesados e de alta saída devem ficar entre os joelhos e os ombros.

❌ Bipagem Cega

Verdade Física

Nunca bipa um bin e guarda no vizinho só porque o bin alvo estava alto demais.

Mapa de Calor & Curva ABC

ZONA A - ALTA ROTATIVIDADE (POWER ZONE) - 80% DAS VENDAS
ZONA B - MÉDIA ROTATIVIDADE - 15% DAS VENDAS
ZONA C - BAIXA ROTATIVIDADE / ITENS PESADOS - 5% DAS VENDAS

O algoritmo de alocação do WMS direciona o Stower para a Power Zone (níveis entre joelhos e ombros) para maximizar a velocidade de saída dos itens mais vendidos.

Roteirização Sistêmica

WMS Pathfinding Algorithm

O sistema calcula a rota em zigue-zague para minimizar os passos do Stower, garantindo que o tempo por tarefa (TPT) seja o menor possível.

Caixa de Amnistia (Amnesty)

Itens encontrados "soltos" no CD devem ser colocados nas caixas de Amnesty. O Problem Solver reintegra o item no sistema sem gerar penalização para quem o encontrou. O objetivo é a verdade do estoque.

Glossário WMS

BIN +
Endereço físico na prateleira (ex: 12-B-04). É a menor unidade de endereçamento no CD.
VNA (Very Narrow Aisle) +
Corredores ultra-estreitos operados por empilhadeiras trilhadas ou robôs.
TOTE +
Caixa plástica padrão usada para o transporte interno de mercadorias.

PS Checklist: Divergence Resolution

Congelar o Bin Virtual (Bloqueio de Picking)
Retirar todos os itens físicos do endereço
Bipar um a um e identificar o "intruso" sistêmico
Corrigir Master Data (Cubagem/Peso) se necessário
Atualizar Inventário e Desbloquear Bin
